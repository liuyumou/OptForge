# ADR-0070: Separate diagnostic admission from adoption

Status: accepted by the user's request to proceed and conduct GPU studies, 2026-11-12.
Implementation: [SPEC-0037](../specifications/SPEC-0037-mixed2-pilot.md).

A 1.10x speedup saves 9.09% latency. It is a provisional practical adoption target
for complex numerical changes, not a mathematical correctness requirement or a
universal threshold for learning from a bounded experiment. SPEC-0036 inherited
the target without an explicit workload-value or statistical-power justification.
The user authorizes correcting that prospective design and running GPU studies.

Admit a bounded prepared-path attribution/storage pilot on useful questions and
exact safety contracts. Measure matrix share, profiling disturbance, FP32-storage
products and a conservative guard. Preserve all costs and distinguish component
observations from complete-solver performance. No pilot can select a public preset.
Later adoption must justify the minimum useful effect and sample size before
confirmation; correct certificates, coverage and scoped regression guards remain.

The MIXED2 cold upper bound (1.010266x) and prepared whole-event 2x forecast
(1.151630x) remain exact historical results. The former motivates prepared focus;
the latter motivates measuring unknown matrix fraction and overhead. Eight pilot
blocks cannot demonstrate production generalization or statistical power for a
later claim. Do not regrade historical results, fund new work from closed budgets,
or treat the pilot as a completed mixed solver. New independent resources and
ordered software/device/four-sanitizer admission are fixed in SPEC-0037.
